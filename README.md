# College Event Management System

A small student project concept for organising college events in one place. The repository documents the idea and its planned features.

## Project Overview

The College Event Management System is intended to help students discover campus events and help organisers share event information clearly.

## Initial Features

- View upcoming college events.
- Read event details such as date, venue, and organiser.
- Find information about registrations and participation.

## Purpose

This project is a learning exercise for practising Git and GitHub basics, including repositories, commits, branches, and pull requests.

## Status

Planning stage. The repository currently contains project documentation only.
